The progress bar visualizes one or more progress values (each between 0 and 1) as horizontal segments. It supports a stacked layout (all segments on one line) and a multiline layout (each segment on its own line). All colors, sizes, and the label are fully configurable.

Summary of Options

Input Type Default Effect
progress number[] [0] Array of progress values between 0 and 1. Each entry becomes a segment. Values above 1 are capped at 100%.
colors string[] [--cds-global-color-green-100] Colors for the segments. If there are fewer colors than progress values, the array cycles.
backgroundColor string var(--cds-global-color-gray-100) Color of the unfilled bar background.
--cng-progress-bar-width CSS length 100% Total width of the bar. Any CSS unit (px, %, vw, clamp(), …).
--cng-progress-bar-height CSS length 10px Total height of the bar. In multiline layout it is split evenly across rows.
--cng-progress-bar-radius CSS length 9999px Corner radius of the bar (default fully rounded/pill).
--cng-progress-bar-gap CSS length 4px Gap between the bar and the label.
--cng-progress-bar-label-min-width CSS length 40px Reserved minimum width for the label so layout doesn't shift.
label number | string undefined Text next to the bar. Numeric values are formatted as a percentage (e.g. 0.72 → "72%"). String values are shown as-is. If not set, no label is rendered.
labelColor string var(--cds-global-color-black-100) Text color of the label.
fontSize number 13 Font size of the label in pixels.
layoutStrategy 'horizontal-stacked' | 'horizontal-multiline' 'horizontal-stacked' horizontal-stacked: all segments share one line and are drawn on top of each other from the left. horizontal-multiline: each segment gets its own line, stacked vertically.
