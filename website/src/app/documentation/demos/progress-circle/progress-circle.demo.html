The progress circle renders one or more progress values (each between 0 and 1) as circular rings. Use the layered layout to stack rings on top of each other, or the concentric layout to draw them as nested rings with a reducing radius.

Summary of Options

Input Type Default Effect
progress number[] [0] Array of progress values between 0 and 1. Each entry becomes a ring. Values above 1 are capped at 100%.
colors string[] ['var(--cds-global-color-green-100)', 'var(--cds-global-color-blue-100)', 'var(--cds-global-color-red-100)'] Colors for the rings. If there are fewer colors than progress values, the color array cycles.
backgroundColorCircle string var(--cds-global-color-gray-100) Color of the background ring behind the progress ring(s).
label number | string undefined Text shown in the center of the circle. Numeric values are formatted as a percentage (e.g. 0.72 → "72%"). String values are shown as-is. If not set, no label is rendered.
layoutStrategy 'layered' | 'concentric' 'layered' layered: all rings share the same radius and overlap. Best for comparing progress values against the same reference. concentric: rings are nested with reducing radius. Best for showing multiple independent progress values in one visual.
Styling (CSS) width / height 100px / 100px Size the circle by setting width and height on the clr-circle-progress-bar element with plain CSS (any unit: px, %, rem, …). Ring thickness is derived automatically from the size and layout.
